## 示例用例类别

- undefined*AI 自动化软件**：以无需人类副驾驶、可在后台运行上百万次的方式，把 AI 与可靠的软件交织在一起。代码掌控控制流（而不是 markdown 文件），同时由 TypeSafe 负责语义决策与语言理解。
- undefined*实时应用**：实时速度（150ms）下的前沿智能意味着 AI 可以比人类感知更快地做出决策。足够快、足够聪明，可被编程来玩游戏或嵌入 UI。
- undefined*大数据上的 AI Map Reduce**：便宜 100 倍意味着你可以处理海量数据集。在庞大的语料中搜索相关信息、对庞大的智能体轨迹做分类、提取特征以做预测。
- undefined*通用验证**：验证任何其它 AI 的输入提示、抽取结果、推理轨迹、工具调用或输入。以实际 LLM 调用成本的一小部分，检测越狱、引用错误、幻觉、错误或其它 AI/LLM 会犯的故障模式。
- undefined*测试台工程（Harness Engineering）**：用 Jev 查询让你的测试台更聪明——模型路由、语义上下文检索、LLM 错误检测与护栏、以极小成本对推理轨迹做高速分类。

## 示例自动化用例

### 搜索与检索

- 用语义搜索、打分与排序，替换或补充 RAG 流水线中的嵌入向量。
- 对查询与候选的相关性打分。
- 用成对比较重新排序结果。
- 对查询与候选做交叉编码以提升精度。
- 为下游 AI 工作流挑选有用的上下文。

### 科学发现

- 按纳入与排除标准筛选论文，用于系统综述。
- 用预定义主题或类别，为访谈转录、开放式调查回答与实地笔记中的段落打标签。
- 检查被引用的段落是否支撑手稿与生成摘要中的主张。
- 标记缺失的方法学细节，如对照组、数据集描述与实验设置。
- 跨论文识别实体与关系，构建研究知识图谱，把发现链接到支撑段落。

### 模型路由

- 用 Jev 构建一个自定义路由器，决定每个提示由哪个 LLM 接收。
- 为你特定的工作流设置路由规则与阈值。
- 对意图与领域做分类。
- 估计难度与风险。
- 把需要更昂贵模型的请求升级处理。

### LLM 护栏

- 以 LLM 调用成本的一小部分，对每一个 LLM 输入、输出与工具调用施加语义检查。
- 检测越狱与提示注入。
- 识别策略违规与敏感数据泄露。
- 实时检测工具调用错误与响应质量故障。
- 记录结构化的检查结果与概率，让 AI 系统与测试台的故障更易追踪。

### 语义代码检查

- 用 Jev 查询为代码与写作添加自动化的语义检查（lint）。
- 为团队的编码规范与写作指南定义检查项。
- 在 CI 中运行这些检查，并标记违规项供复核。

### 面向预测建模的特征提取

- 用 Jev 从自然语言数据中提取概率性特征。
- 把这些特征与结构化数据结合，训练面向有真实结果任务的模型。
- 用 autoresearch 工作流提出特征定义，并针对留出真实值评估其预测价值。

### 招聘

- 依据明确的、与岗位相关的标准评估简历、申请与面试反馈。
- 识别相关经验。
- 为所需胜任力打分。
- 把候选人与岗位做匹配。
- 把候选人路由给招聘经理或招聘人员。
- 把不确定的案例升级给人工复核。

### 潜在客户生成

- 把公司画像、高管简介与入站消息匹配到理想客户画像（ICP）。
- 对公司契合度与成熟度打分。
- 检测买家相关性、痛点与购买意向。
- 对线索排优先级并路由。

### 客户支持

- 按问题、产品领域与客户意图对入站工单分类。
- 处理通话转录，抽取客户问题、承诺与后续动作。
- 检测紧迫性、沮丧程度、流失风险与退款请求。
- 把案例路由到正确的团队、队列或自动化工作流。
- 对照政策与客户请求，验证支持回复。

### 保险理赔

- 对首次损失通知报告、定损员备注与支撑文档分类。
- 检测案件复杂度、信息缺失与潜在欺诈迹象。
- 为直通处理或专家复核排定优先级。
- 把不确定或高风险的案例升级给人工定损员。

### 金融犯罪

- 评估交易叙述、KYC 文档与告警历史中的可疑特征。
- 在不一致的名称、画像与记录之间匹配实体。
- 按风险、相关性与证据质量排定告警优先级。
- 把模糊的案例路由给调查员复核。

### 法律与合规

- 对合同、政策、监管申报与营销主张分类。
- 检测缺失条款、违规主张与策略违规。
- 对照明确的法务或合规要求验证文档。
- 把高风险或不确定的发现升级给法务或合规团队。

### 电商市场

- 在不一致的卖家目录之间，对商品列表做分类与规范化。
- 从标题与描述中提取商品属性。
- 检测违规列表、假冒信号、评论滥用与策略违规。
- 对商品排序，把不确定的列表路由给人工复核。

### 内容审核与信任安全

- 应用公司特定的、细致的准则，判断哪些帖子符合你的审核标准。
- 在社群、客户支持与 SDR 工作流中，对用户内容与自动化对话做审核。
- 检测毒性、骚扰、垃圾信息、欺诈、不安全建议、个人数据泄露、退订请求与违规主张。
- 结合严重程度与 confidence，决定允许、警告、复核还是屏蔽内容。

### 广告

- 评估创意素材、广告文案、落地页与投放上下文。
- 对品牌安全性与受众适配性分类。
- 检查监管合规与违规主张。
- 评估创意质量与广告到落地页的一致性。

### 游戏

- 评估玩家报告、游戏内聊天、评论与支持对话。
- 审核聊天，检测滥用、毒性或可疑行为。
- 标注内容，对沮丧程度或参与度打分。
- 检测流失信号，并路由玩家支持请求。

### 风险评估

- 把事故报告、理赔备注、交易描述与供应商评估转换为概率性风险指标。
- 在保险与承保工作流中使用这些指标。
- 对风险类型分类，并检测可疑特征。
- 对严重程度打分并排定复核优先级。
- 为更广的风险模型提取特征。

### 需求预测

- 用来自客户咨询、销售记录、商品评论、支持工单与市场报告中的语义信号，丰富预测模型。
- 提取购买意向、紧迫性与产品兴趣。
- 检测供应担忧、竞争压力与新兴需求主题。
- 把这些特征与历史时间序列数据一起输入预测模型。

### 图谱与知识图谱

- 用类型化的语义决策标注并验证知识图谱。
- 对关系与实体类型分类。
- 检测记录或主张之间的矛盾。
- 支持概率性遍历与层级分类。

## 示例任务类别

| 决策形态 | 当你需要… | 示例 |
| --- | --- | --- |
| Classification | 有一个已知类别应当胜出 | 意图、主题、部门、风险类型、实体类型 |
| Detection | 需要某个属性存在的概率 | 垃圾信息、欺诈、紧迫性、越狱、敏感数据 |
| Scoring | 答案落在有序的量表上 | 严重程度、相关性、质量、沮丧程度、适配性 |
| Routing | 由某个类别选择下一条代码路径 | 工具使用、升级、模型路由、支持队列 |
| Search | 需要找到匹配自然语言查询的项 | 语义搜索、文档发现、候选生成 |
| Retrieval | 工作流需要最相关的上下文或记录 | RAG 上下文、证据检索、知识查找 |
| Ranking | 需要按语义相关性或质量对项排序 | 搜索结果、推荐、候选排定优先级 |
| Verification | 必须针对特定故障模式检查某个产物 | 引用支撑、策略违规、工具调用错误、响应质量 |
| ML Feature Extraction | 下游经典 ML 模型需要语义信号 | 购买意向、产品兴趣、竞争压力、流失信号 |
| Structured Data Extraction | 必须从非结构化输入中恢复已知字段 | 候选属性、订单字段、文档标签 |
