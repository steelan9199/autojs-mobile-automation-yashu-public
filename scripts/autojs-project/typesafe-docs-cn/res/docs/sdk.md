> 安装一个 TypeSafe 客户端 SDK，在应用里使用类型化的问题与答案。

我们的客户端 SDK 为 TypeSafe API 提供类型化的问题与答案，并通过默认重试策略自动处理重试。

选择一个客户端 SDK，查看安装说明、示例与 API 细节。

## 可用的 SDK

- [Python](https://docs.typesafe.ai/sdk/python) —— 安装 Python 客户端 SDK，发出你的第一次请求。
- [JavaScript / TypeScript](https://docs.typesafe.ai/sdk/javascript) —— 安装 JavaScript 客户端 SDK，发出你的第一次类型化请求。

你也可以用任何语言直接调用 [HTTP API](https://docs.typesafe.ai/api)。
