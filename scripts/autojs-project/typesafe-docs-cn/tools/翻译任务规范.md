## 第 2 步：读源文件并写 frontmatter

英文源开头的 front-matter 只有 **3 个字段**，产物要 **7 个**，映射关系：

| 源（英文） | 产物（中文 md） | 怎么来 |
| --- | --- | --- |
| `slug` | `slug` | **原样照抄** |
| `title_en` | `titleEn` | **原样照抄**（注意字段名是 camelCase） |
| `url` | `url` | **原样照抄** |
| — | `title` | `title_en` 的**中译** |
| — | `group` | 查 `res/data/00-index.js` 的 `plan`，看这页归在哪个组 |
| — | `order` | 同上看它在 `plan` 里的位置；**全站连续正整数**，新页取当前最大 +1 |
| — | `summary` | 自己写一句话（≤40 字），进列表与搜索 |

产物 frontmatter 的形状（**顺序照抄**）：

```
---
slug: cookbooks/rerank_typesafe
group: cookbook
order: 4
title: 重排序
titleEn: Re-ranking
url: https://docs.typesafe.ai/cookbooks/rerank_typesafe
summary: 用 Choice 对候选段落两两比较，按与 query 的相关性重新排序。
---
```

文件名 = `slug` 里的 `/` 换成 `__` + `.md`（例：`cookbooks/rerank_typesafe` → `cookbooks__rerank_typesafe.md`）。

## 第 3 步：译正文（这是最容易做错的地方）

1. **说明文字全部译成简体中文；代码块一律英文原文照抄，一个字符都不许改。**
   代码块包括：Python、JSON、TypeScript、JavaScript、bash/cURL、SQL、mermaid，以及任何「程序输出样例 / 数据预览」。
2. **绝对不许摘要、不许省略、不许合并段落、不许写「以下略」。**
   英文原文有多少个 `##` / `###` / 段落，中译就要有对应的（可因拆分变多，**绝不允许更少**）。
   代码块要**全部**收录，一个都不能跳 —— cookbook 的价值就在代码里。
3. 术语首次出现写「中文（English）」，之后只用中文。下列**一律保留英文**（代码里的字面量，译了没法用）：
   `Jev`、`System One`、`Choice`、`Score`、`Noul`、`state`、`instructions`、`criteria`、`confidence`、
   `probabilities`、`legend`、`threshold`、`fan-out`、`model`、`usage`、`input_tokens`、`output_tokens`、
   所有函数名 / 类名 / 方法名 / 字段名 / 变量名 / 模型 id（如 `jev-1.13.0`）/ SDK 名 / CLI 命令。
4. 作为**输入数据的示例素材**（商标分类名、商品类目、评审意见原文、语料样例、模型输出样例等被评估的内容）
   属于数据，**保留英文原文照抄**，不要翻译。
5. **标题**：源的 `# 大标题` **整行丢弃**（标题由 frontmatter 的 `title`/`titleEn` 承载，
   正文写 h1 会触发体检警告）。`## ` / `### ` 层级照留、文字译中文。正文**至少一个 `## `**，否则报错。
6. **链接**：站内相对链接（`/primitives/choice`）改写为绝对地址 `https://docs.typesafe.ai/primitives/choice`。
   - 纯锚点链接 `[文字](#some-anchor)` → 去链接只留文字。
   - `mailto:` → 去链接只留邮箱纯文字。
   - 只允许 `https://` 开头；写 `#` / `//` / http 的会**报错**。
7. **裸 HTML 一律清掉**（会报错）：
   - `<img>` / `<iframe>` / `<div>` / `<span>` → 一行引用说明：`> （原文此处有一张示意图：<简述内容>。）`
   - `<Tip>` / `<Warning>` / `<Note>` → `> **提示：** …` / `> **注意：** …`
   - 其余行内 HTML → 去标签只留文字。（`<br>` `<hr>` `<!-- -->` 豁免）
8. **表格原样保留为 Markdown 表格**；单元格文字译中文，单元格里的代码与字面量保留英文。
9. **不要用斜体**（`*(required)*` 写成 `（必填）`）。行内只允许 `**加粗**`、`` `行内代码` ``、`[文字](https://…)`。
10. 一个长段超过 ~200 字就拆成多段。
11. 原文若出现被自己截断的长块（结尾是 `...`），**照抄即可，不要补全**。
12. **编码**：UTF-8、LF 换行、无 BOM、结尾有换行符。
