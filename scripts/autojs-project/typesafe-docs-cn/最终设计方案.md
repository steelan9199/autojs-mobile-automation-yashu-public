# typesafe 文档 App · 最终设计方案

> 2026-09-22 定稿。所有依赖版本、体积、API 可用性均为**实测值**（下载量字节 + 无头 Chrome 跑通），非经验估计。

## 0. 一句话

**内容与渲染彻底解耦**：46 个中文 `.md` 是唯一真源，`page.html` 退化成纯外壳，渲染/样式/高亮全部交给三个成熟依赖——**加一页 = 往 `res/docs/` 丢一个文件，零代码、零构建、不进构建链路**。

## 1. 先定义"尽可能少地携带"

它**不是**"产物体积小"（首屏启动速度不是约束，不需要为省 85KB 引入一次性构建工具）。它指两件事：

| 含义 | 落在哪 |
| --- | --- |
| **少携带自研代码** | 删掉自写渲染器 721 行 + 自写主题 489 行 = **净减 1210 行自研代码**，改由依赖承担 |
| **不携带冗余数据** | 删掉 `res/data/*.js`（**575 KB**，内容已全部迁入 md） |
| **不携带构建工具链** | 不引 webpack / vite / esbuild，不产生 `node_modules`（100MB+）与构建配置 |

⛔ **不做的**：不裁剪 `highlight.js`（裁剪只省 85KB，代价是引入 esbuild 一次性构建、且原文新增语言时要重建）。直接使用官方全量构建。

## 3. 否掉的候选（含理由）

| 候选 | 否掉的理由 |
| --- | --- |
| `markdown-it` | dist 压缩后 **123,618 B**，是 marked 的 2.6 倍，且带 6 个运行时依赖 |
| `prismjs` | ★13,042，但**开放 issue 495**（marked 17 个、highlight.js 112 个），维护明显滞后；无官方预构建单文件 |
| `micromark` | 17 个运行时依赖，违背"架构简单" |
| `snarkdown` | 仅 ~2KB，但不支持 GFM 表格——原文表格多，直接不可用 |
| `DOMPurify` | 内容是自译可信的，无 XSS 攻击面；不引 sanitize，省一层 |
| `mermaid` | 渲染库约 1MB；mermaid 代码块按纯文本展示 |
| webpack / vite / esbuild | 依赖**官方就是 UMD 单文件**，打包器唯一收益是 minify（产物本就是 `.min`）；代价是 `node_modules` + 配置 + `file://` 下 ESM 产物被拦的不确定性 |

## 4. 四层架构

```
内容层（唯一真源）    res/docs/*.md（46 个，明文）
                     + 每页 frontmatter（slug/group/order/title/titleEn/url/summary）
                            ↓
构建层（PC 侧一条命令） build-page.cjs：把 res/vendor/* 就地内联
                     → res/page.html（单文件外壳 296 KB / 46 页齐全）
                            ↓
运行层（手机）         WebView 加载 page.html
                     → page.jsBridge（AutoJs6 官方桥，挂在 WebView 变量 `page` 上）按页读 md
                     → 浏览器本地缓存：搜索索引 + 阅读位置
                            ↓
渲染层（全交依赖）      marked 18.0.14 + github-markdown-css 5.9.0 + highlight.js 11.12.0
```

**关键机制说明**

| 机制 | 做法 | 为什么 |
| --- | --- | --- |
| 读 md | `$autojs.invoke('read-doc', {slug})` → 安卓侧 `files.read()` | `fetch('file://')` 与 `<script type="module">` 在 WebView 里**必被拦**（规范层限制，非开关）；jsBridge 是 AutoJs6 官方通道，写法是 **`<WebView 变量名>.jsBridge`**（本工程 = `page.jsBridge`，⛔ 不是全局 `web`） |
| 导航与分组 | 运行时扫 `res/docs/` 读各页 frontmatter 拼出 | 加页不改 `00-index.js`，才真正"丢文件即可" |
| 搜索 | 运行时扫目录建索引 → 存本地缓存，按 `文件名+大小+修改时间` 失效 | 懒加载后内存里没有全文；搜索必须全量，但**不能靠构建期预生成**（否则加页要重跑构建） |
| 代码高亮 | 抽屉打开时对当前页执行 `hljs.highlightElement()` | 不批量高亮 46 页 |
| 打包安全 | vendor **必须内联**进 `page.html` | `.js` 打包后被 AES 加密，WebView 不解密 → 白屏；`.md`/`.css`/`.html` 实测为明文 |

## 5. 渲染层实施注意（实测得出，直接照做）

1. **未注册语言要跳过**：`hljs` 官方 common 版含 `plaintext`，但**不含 `mermaid`**。高亮前先判 `hljs.getLanguage(lang)`，未命中就原样展示，否则 `highlightElement` 抛错中断整页渲染。
2. **`marked` 默认开 GFM**，表格无需额外配置；代码块自动产出 `language-xxx` class，`hljs` 直接可认。
3. **自译 md 不写 h1**（标题由外壳渲染），只写 `##` 及以下，配合页内目录。
4. **代码块语言标注**：原文 35 页实际只用到 `python`/`text`/`json`/`bash`/`jsx`/`mermaid`/`typescript`/`javascript`/`http`（151/71/32/22/12/11/1/1/1 个）。`highlight.js` 里 `sh` 是 `bash` 的别名、`jsx` 归 `javascript`，可直接命中；
   ⚠️ **修正（2026-09-22 M1 实测）**：官方 common 版**不含 `mermaid`，也不含 `http`** —— 原文里 **12 个代码块**（mermaid 11 + http 1）会退化为无高亮。这是预期行为（第 1 条已兜住），但不要把"未注册语言只有 mermaid"当成事实。

### 10.2 三条实测修正（写进本文件，别按旧认知做）

1. **`http` 语言在 highlight.js common 版里也不存在**（原文 1 个块）。第 5 节第 4 条已改。
   实际退化为无高亮的是 **12 块**：`mermaid` 11 + `http` 1。
2. **`marked@18` 不给标题生成 `id`**（slugger 已移除）。页内目录的锚点由 `app.js` 按 DOM 顺序自己补
   （`sec-N`），再与围栏感知扫出的 `## / ###` 列表一一对应。
3. **`marked` 固定给代码块内容补一个尾部 `\n`**，在 `<pre>` 里就是底部多一条空行。
   `app.js` 在渲染后把 DOM 侧的尾换行 trim 掉，保证 DOM ≡ md 原文（复制出来的也没有尾巴空行）。

### 10.3 两个必须知道的实现细节

1. **压住 vendor 的深色分支。** `github-markdown-css` 带 `@media (prefers-color-scheme: dark)`，
   手机开深色模式会给正文铺 `#0d1117`。媒体查询不增加优先级，所以 `style.css` 用
   `#sContent.markdown-body`（1,1,0）重新声明浅色变量，压过 vendor 的 `.markdown-body`（0,1,0）。
   已实测：在 `style.css` 之前插一段**无条件生效的** `.markdown-body` 深色变量，正文仍是浅色。
2. **正文装载是三级回退，且必须同步。** 抽屉是同步绘制的，所以 `readDoc()` 只能走同步路径：
   `window.DOC_MD[slug]`（page.html 内联）→ `$autojs.invoke('read-doc')`（M2）→ 同步 XHR 直读 `docs/*.md`（浏览器预览）。
   已实测同步 XHR 在 `file:// + --allow-file-access-from-files` 下可读、缺文件会抛错（可判定）。

### 10.4 M1 期间**有意留到 M2/M3** 的三件事

1. `main.js` 的运行期合成兜底分支**还没实现 `<!--DOCS-->`**。正常路径（读 `page.html`）不受影响；
   只有在 `page.html` 缺失时才会走到，那条路在 APK 形态下本来就不可用（vendor 是 `.js` 密文）。
2. 每页元信息仍在 `00-index.js`，**md 还没有 frontmatter**。「加一页只丢文件、不改数据」要等 M2
   把导航改成运行时扫 `res/docs/` 读 frontmatter 之后才真正成立。
3. `res/data/_SCHEMA.md` 描述的还是旧「9 种块」契约，**已过时**，等 M4 重写。

### 11.3 三条实测教训（M2 期间踩到，已写进 `技术决策记录.md` D-04）

1. **HTML 注释不能嵌套**：注释里逐字写占位符会把外层注释截断 → 占位符出现两次 → `--inline` 把正文内联两遍（820 KB 变 1.35 MB）。已加"必须恰好一次"断言。
2. **`String.replace(pat, str)` 会解释 `$&` / `` $` `` / `$'`**：注入整份 md 时会注入坏内容。已全部改为函数式替换。
3. **抽屉同步语义得以保留**：真机若 `file://` 同步 XHR 可用，正文**根本不会看到骨架**；桥只在同步通道落空时兜底。
