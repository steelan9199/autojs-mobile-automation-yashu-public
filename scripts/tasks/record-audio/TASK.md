# record-audio · 麦克风录音

## 使用场景

- 需要录制手机周围的声音（如抖音视频外放、人说话、环境音）
- 录音后需要回传电脑做 ASR 语音识别
- 作为"听音频→理解内容"流水线的第一步

## 什么时候不该用

- 需要录制手机系统内部音频（应用内录）——本模板只能录麦克风，Android 限制普通应用无法内录其他应用的声音
- 需要录制视频——用 `recstudio` 录屏方案
- 只需要短提示音——用 `make-beep` 模板生成

## 参数细节与坑

| 参数 | 类型 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| `duration` | number | 否 | 10 | 录音时长（秒）。建议 5~15 秒，太长文件大、回传慢 |

**音频规格**：44100Hz 采样率、16bit 位深、单声道、WAV 格式。10 秒约 882KB。

**音频源选择**：优先用 `CAMCORDER`（部分机型对高频响应更好、降噪更自然），初始化失败自动退化为 `MIC`。

**输出路径**：`/sdcard/录音/record_<时间戳>.wav`，每次录音生成新文件，不覆盖。

## 错误处理与兜底

| 错误信息 | 原因 | 处理建议 |
|----------|------|----------|
| `无录音权限。请在手机设置…` | 麦克风权限被拒 | 引导用户去系统设置授权，或首次运行时点"允许" |
| `AudioRecord 初始化失败，麦克风可能被其他应用占用` | 其他 App 正在用麦克风（如微信语音、电话） | 关闭占用麦克风的应用后重试 |
| `录音文件过小或不存在` | 录音过程中出错 | 检查存储空间是否充足，重试 |

**权限请求机制**：脚本启动时检查 `RECORD_AUDIO` 权限，未授权时调用 `activity.requestPermissions` 弹出系统授权对话框，等待 2.5 秒让用户点击"允许"后再检查。如果用户拒绝，返回明确的权限错误。

## 示例调用

```bash
# 录 10 秒（默认）
node scripts/run-task.js record-audio

# 录 5 秒
node scripts/run-task.js record-audio --args '{"duration": 5}'

# 录 15 秒
node scripts/run-task.js record-audio --args '{"duration": 15}'
```

成功返回：
```json
{"ok":1,"path":"/storage/emulated/0/录音/record_1789399388002.wav","size":882044,"duration":10,"format":"wav"}
```

拿到 `path` 后，用 `download-file` 模板把音频回传电脑，再用 `mediakit-cli video asr-subtitles --audio-url <本地路径>` 做语音识别。

## 红线提醒

- 本模板只录麦克风，**无法录制手机内部音频**（Android 系统限制），需要内录请用系统录屏功能
- 录音前确保没有其他应用占用麦克风（微信通话、电话、语音助手等）
- 录音文件存在 `/sdcard/录音/` 目录，长期使用需定期清理避免占满存储空间
