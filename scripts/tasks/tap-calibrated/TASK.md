# tap-calibrated · 按名点按球球画板控件

## 使用场景
作画流程里所有"点画板界面按钮/色块"的动作（选色、选笔粗、切画笔/橡皮擦、铺背景/边框、撤销/重做/清空、回放、生成皮肤、返回），坐标已由 `qiu-calib` 标定并存在手机存储，用本模板按名直读坐标点按——不依赖文档估算值，坐标准确且跨会话持久。

## 什么时候不该用
- 未做过标定的名字 → 会返回 `{ok:0, err:"未标定: ..."}`，先启动 `qiu-calib` 补标定；
- 需要坐标数值本身（如算曲线、传给人看）→ 用 `qiu-calib-read` 的 `op=list` 读取；
- 非画板界面的普通坐标点按 → 用 `tap-point`。

## 参数细节与坑
- `name` 必填，必须是 `qiu-calib` 标定过的键名（中文，如 白 / 撤销 / 粗笔 / 生成皮肤）。
- 标定时记录了屏幕方向：当前方向与标定时不一致会拒绝点击并提示转屏（防横竖屏坐标错位）。
- 成功回执带 `x,y` 便于 PC 侧记录核验。

## 示例调用
```bash
node scripts/run-task.js tap-calibrated --args '{"name":"白"}'
# → {"ok":1,"x":240,"y":1130}

node scripts/run-task.js tap-calibrated --args '{"name":"撤销"}'
# → {"ok":1,"x":275,"y":1275}
```

## 红线提醒
- 未标定返回 err、**绝不静默用旧估算值瞎点**——坐标错位会造成误触（如误清空画板）；
- 点击是真实操作，按名字谨慎调用（生成皮肤 = 触发上传/发布流程，需先向用户确认）。
