## ⚠️ 已被推翻的结论（读旧报告前必看）

- **`AutoJS6官方文档_内置模块说法核查报告.md`**：该报告称 `events` "虽能 require，但返回的是**空壳**"。
  **此结论已作废**（第 6 轮推翻）：`Object.keys()` 对 Java 宿主对象恒返回 0，旧判据用错了测量方法；
  实测 `require("events") === 全局 events`，是 AutoJs6 自己的 EventEmitter（`for...in` 51 个成员）。
  → 该报告中**只有 `events` 这一条**作废，其余（6 项 `Module not found`、`require.resolve` 未实现、
  `node:` 前缀全失败）仍然成立。**以第 6 轮报告与细则 §7.8 为准。**

（`temp/` 会被整目录清理，放进去等于自断复现路径）。
